# Glossary Map

## Contexts

- [Infrastructure](./docs/GLOSSARY.md): hosts, the stacks they run, their exposure, and how changes reach them (switch, deploy, sync). Decisions in `docs/adr/`, created with the first one.
- [Desktop](./configs/design/GLOSSARY.md): what sits on the screen of a workstation and the states it can be in, on macOS and Linux. Decisions in `configs/design/decisions/`.

## Relationships

- **Infrastructure → Desktop**: the desktop runs on the two workstations; every other host is a server and has none.
